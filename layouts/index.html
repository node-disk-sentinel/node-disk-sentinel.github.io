Autonomous Disk Health & Telemetry

{{ .Site.Params.tagline }}

A Kubernetes-native DaemonSet that autonomously discovers physical disks on every node, assesses their health via a prioritized multi-protocol SMART cascade, publishes live telemetry into cluster-scoped PhysicalDisk resources, and exports Prometheus metrics.

Quickstart Installation {{ partial "icon.html" (dict "name" "github" "class" "icon-btn") }} View on GitHub

Lightweight & Resilient Architecture

No separate smartd daemon or heavy control planes. Direct kernel integration with standard Kubernetes controllers.

Host udev & Netlink

Scans /run/udev/data and listens to kernel Netlink group 2 for hotplug add, remove, and offline events.

Smartmontools Runner

Privileged host engine running smartctl with safe power-state handling and robust device fallback.

Health Assessment

Deterministic, prioritized SMART health assessment for ATA, NVMe, and SCSI devices classifying drives into explicit health categories.

Kubernetes CRD & Metrics

Publishes cluster-scoped PhysicalDisk records and exposes Prometheus metrics.

Built for Production Clusters

Reliable telemetry designed for bare-metal Kubernetes, Harvester, Ceph/Rook, and Longhorn storage nodes.

{{ partial "icon.html" (dict "name" "heart-pulse") }}

Prioritized Assessment

Prioritized multi-protocol severity cascade evaluating device self-tests, hardware threshold violations, sector errors, and past failures.

{{ partial "icon.html" (dict "name" "harddisk") }}

NVMe & SCSI Support

Native parsing of NVMe health logs (available spare, critical warnings, media errors, wear percentage) and SCSI error counters.

{{ partial "icon.html" (dict "name" "tune") }}

Per-Disk Configuration

Apply custom smartctl options for RAID controllers, USB bridges, and non-standard hardware. Changes take effect immediately.

{{ partial "icon.html" (dict "name" "sleep") }}

Sleep & Standby Aware

Preserves low-power states of spinning disks by skipping checks on standby media without false degradation alerts.

{{ partial "icon.html" (dict "name" "timeline") }}

Prometheus Metrics

Exports complete smartctl_device_* metrics on :8080/metrics, compatible with existing Prometheus and Grafana dashboards.

{{ partial "icon.html" (dict "name" "shield-check") }}

Node Scoped & Secure

Cache-scoped Informers prevent O(N²) cluster watch fan-out. Sender credentials ensure udev events cannot be forged.

Quickstart Installation

Deploy in seconds using the split Helm charts for clean lifecycle management.

Helm Deployment (Recommended) 
# 1. Install the CustomResourceDefinition chart (with keep policy on uninstall)
helm upgrade --install node-disk-sentinel-crd \
  oci://ghcr.io/node-disk-sentinel/charts/node-disk-sentinel-crd \
  --namespace nds-system \
  --create-namespace

# 2. Install the DaemonSet monitor chart
helm upgrade --install node-disk-sentinel \
  oci://ghcr.io/node-disk-sentinel/charts/node-disk-sentinel \
  --namespace nds-system
Verify Discovered Disks
